# jeakob — GMMK Pro Rev1 ISO firmware

Custom QMK firmware for the Glorious GMMK Pro Rev1, ISO UK layout.

## Download

**[gmmk_pro_rev1_iso_jeakob.bin](gmmk_pro_rev1_iso_jeakob.bin)**

Flash with [QMK Toolbox](https://github.com/qmk/qmk_toolbox) or `dfu-util`. To enter bootloader: hold **FN** then press **Backspace** (or **B**).

## Key reference

**[Full keymap documentation → KEYMAP.md](KEYMAP.md)**

Quick summary:

- **FN + Z** — night mode (all LEDs off; idle timeout capped at 1 min)
- **FN + knob press** — system sleep / Lock Screen (LEDs off immediately)
- **FN + knob rotate** — adjust RGB idle timeout
- **FN + R / P** — record / play macro
- **FN + ESC** — reset all settings to defaults
- **FN + Backspace** — enter bootloader

See [KEYMAP.md](KEYMAP.md) for the complete reference including all shortcuts, RGB controls, toggle settings, OS behaviour, and autocorrect word list.
